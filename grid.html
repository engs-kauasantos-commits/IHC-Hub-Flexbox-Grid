O que é CSS Grid?

CSS Grid é um recurso do CSS que permite organizar elementos em linhas e colunas, facilitando a criação de layouts.

Algumas propriedades importantes são:

  • display: grid - ativa o Grid.
  • grid-template-columns - define as colunas.
  • grid-template-rows - define as linhas.
  • gap - define o espaço entre os elementos.

Definindo colunas e espaços

A propriedade grid-template-columns define quantas colunas existem e como elas dividem o espaço disponível. 


.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 15px;
}

O valor repeat(3, 1fr) cria três colunas com a mesma proporção. A propriedade gap define o espaço entre as caixas.

Onde o Grid é utilizado?

O Grid pode ser usado em galerias de imagens, páginas com cartões, painéis e layouts que precisam organizar elementos em linhas e colunas.
