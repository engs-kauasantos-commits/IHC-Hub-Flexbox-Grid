O que é Flexbox?

Flexbox é um recurso do CSS que ajuda a organizar os elementos de uma página, facilitando o alinhamento e a distribuição dos espaços.

Algumas propriedades importantes são:

  • display: flex - ativa o Flexbox.
  • justify-content - alinha os elementos no eixo principal.
  • align-items - alinha os elementos no eixo transversal.
  • flex-direction - define a direção dos elementos.
  • flex-wrap - permite que os elementos quebrem para outra linha.

Alinhamento dos elementos

A propriedade justify-content controla a distribuição das caixas no eixo principal. 


.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

O valor space-between distribui o espaço entre as caixas. Já o align-items controla o alinhamento no outro eixo.

Direção e quebra de linha

Com flex-direction: column, os elementos ficam um abaixo do outro. Com flex-wrap: wrap, eles podem passar para outra linha quando não existe espaço suficiente. 


.container {
  display: flex;
  flex-direction: row;
  flex-wrap: wrap;
  gap: 10px;
}

Onde o Flexbox é utilizado?

O Flexbox pode ser usado em menus, botões, cartões, cabeçalhos e outros elementos de sites que precisam de alinhamento e organização.
